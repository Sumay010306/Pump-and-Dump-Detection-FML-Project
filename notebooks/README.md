# ML notebook walkthrough

Open these notebooks from the project root, in order. Use the Python 3.13 environment from the main README, then install `requirements-notebook.txt` and select that environment as the notebook kernel.

1. `01_data_features_and_split.ipynb`: historical candles, labels, past-only features and chronological partitions.
2. `02_train_and_select_models.ipynb`: run the exact training function used to produce the dashboard artifacts. This can take a while and **overwrites** the existing model and evaluation files.
3. `03_evaluation_and_explanations.ipynb`: verify the saved test metrics, inspect event detection, feature importance and a local explanation.

The dashboard reads `artifacts/report.json`, `artifacts/predictions.csv.gz`, the CSV evaluation tables and `artifacts/best_model.joblib`. Notebook 02 generates the training outputs through the same project function. Run `python -m pumpwatch.reporting` afterward to refresh reporting tables. The notebooks do not claim to have been executed unless you run them; the included artifacts were generated by the project pipeline.

These are historical results on collected event and comparison days, not a live detector. A positive label covers the onset minute and the next two minutes. Nearby ambiguous minutes are excluded. Scores are not calibrated probabilities.
